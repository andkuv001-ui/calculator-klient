# Калькулятор пакетов — Telegram Web App

Калькулятор расчёта стоимости пакетов с печатью, встроенный в Telegram бота.

## Как это работает

1. Клиент открывает бота в Telegram и нажимает кнопку **"📦 Рассчитать пакеты"**
2. Открывается веб-приложение (Web App) прямо в мессенджере
3. Клиент выбирает тип, размер, тираж и доп. услуги
4. Нажимает **"Отправить заявку менеджеру"** — данные автоматически приходят вам

## Установка

### 1. Создайте бота в Telegram

1. Напишите **@BotFather** в Telegram
2. Отправьте `/newbot`
3. Задайте имя и username бота
4. Скопируйте полученный **токен**

### 2. Настройка

```bash
# Установите зависимости
pip install -r requirements.txt

# Создайте файл .env и вставьте токен
cp .env.example .env
# Отредактируйте .env и вставьте BOT_TOKEN=<ваш_токен>
```

### 3. Настройка Web App в BotFather

1. Напишите **@BotFather**
2. Отправьте `/setmenubutton` или `/mybots` → выберите бота → **Menu Button**
3. Установите URL: `https://andkuv001-ui.github.io/calculator-klient/`
4. Задайте текст кнопки: `📦 Рассчитать пакеты`

### 4. Запуск бота

```bash
python bot.py
```

### 5. GitHub Pages (для хостинга калькулятора)

1. Зайдите в **Settings** → **Pages** репозитория
2. В **Source** выберите ветку `main` и папку `/ (root)`
3. Нажмите **Save**
4. Калькулятор будет доступен по адресу: `https://andkuv001-ui.github.io/calculator-klient/`

## Возможности калькулятора

- 4 типа пакетов: вертикальные, горизонтальные, чёрные, прозрачные
- Автоматический расчёт стоимости печати по группам
- Дополнительные услуги: доп. цвет, золото/серебро, подготовка макета
- Отправка заявки прямо из Telegram
- Работает на мобильных устройствах
