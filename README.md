# Калькулятор пакетов — Telegram Web App

Калькулятор расчёта стоимости пакетов с печатью, встроенный в Telegram бота.

## Как это работает

1. Админ пишет `/post` в канале или группе
2. Бот публикует сообщение с кнопкой калькулятора и закрепляет его
3. Клиент нажимает кнопку → открывается калькулятор → заполняет параметры
4. Нажимает **"Отправить заявку менеджеру"** — данные приходят в канал/группу

## Установка

### 1. Создайте бота в Telegram

1. Напишите **@BotFather** в Telegram
2. Отправьте `/newbot`
3. Задайте имя и username бота
4. Скопируйте полученный **токен**

### 2. Настройка

```bash
pip install -r requirements.txt
cp .env.example .env
# Отредактируйте .env и вставьте BOT_TOKEN=<ваш_токен>
```

### 3. GitHub Pages (хостинг калькулятора)

1. **Settings** → **Pages** репозитория
2. Source: ветка `main`, папка `/ (root)`
3. Save
4. Калькулятор: `https://andkuv001-ui.github.io/calculator-klient/`

### 4. Запуск бота

```bash
python bot.py
```

### 5. Настройка в канале

1. Добавьте бота `@calculator_klient_bot` в канал как **администратора**
2. Права: **Публикация сообщений** (обязательно)
3. Напишите `/post` в канале — бот опубликует сообщение с кнопкой и закрепит его
4. Клиент нажимает кнопку → открывается калькулятор → отправляет заявку

> **Важно:** В каналах кнопка открывает калькулятор в браузере (не в WebView). Клиент заполняет расчёт и копирует результат через кнопку внизу.

### 6. Настройка в группе

1. Добавьте бота в группу, сделайте **администратором**
2. Напишите `/post` — бот опубликует сообщение с кнопкой и закрепит его
3. В группах кнопка открывает Web App прямо в Telegram (полный функционал)

### 7. Личные сообщения

- Напишите `/start` боту в личку
- Появится кнопка внизу экрана
- Калькулятор открывается в Telegram Web App

- 4 типа пакетов: вертикальные, горизонтальные, чёрные, прозрачные
- Автоматический расчёт стоимости печати по группам
- Доп. услуги: доп. цвет, золото/серебро, подготовка макета
- Отправка заявки из Telegram
- Работает на мобильных устройствах
